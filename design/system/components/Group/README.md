# Group

Nomme plusieurs contrôles ensemble, là où un seul libellé ne suffit pas : une liste de domaines, un jeu de cases, une ligne avec un bouton.

- Un `<fieldset>` : légende en `color-muted`, aide en `color-faint`.
- Les cases et boutons radio prennent un fond `color-status` au survol, `radius-md`.

Source : `web/src/ui.tsx`.
