# Icon

Une icône lucide à la taille de l'interface : 16px, trait 1,5, couleur du texte, masquée aux lecteurs d'écran.

- Le consommateur fournit `icon` (un composant lucide-react). Le bundle en expose quelques-unes dans `MyInfra.icons`.
- Une icône seulement quand elle distingue une action ou une rubrique.

Source : `web/src/ui.tsx`.
