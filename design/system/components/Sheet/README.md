# Sheet

Le dialogue : une feuille qui monte du bas sur téléphone, une boîte centrée sur un écran large.

- Voile `color-ink` à 40 %, panneau `color-surface`, filet `color-line`, `radius-md`, titre en `lead`.
- Le focus reste dedans et revient où il était à la fermeture ; Échap et un clic sur le voile ferment, sauf pendant `busy`.
- Le consommateur fournit `title`, `onClose`, le contenu, et `wide` pour un formulaire plus large.

Source : `web/src/kit.tsx`.
