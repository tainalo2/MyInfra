# Input

Le champ texte, pleine largeur.

- `color-surface`, filet `color-line`, `radius-md`, padding `space-2` × `space-3` ; la bordure passe à `color-focus` quand il est actif.
- Toujours dans un `Field`. Un domaine, une commande ou une empreinte se tapent en `mono`.
- Tous les attributs d'`<input>` passent ; `className` s'ajoute aux classes de base.

Source : `web/src/ui.tsx`.
