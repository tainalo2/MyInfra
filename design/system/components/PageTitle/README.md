# PageTitle

Le titre de page (`h1`) et son action principale à droite.

- `page-title` (24px, 500) à partir de 768px, `page-title-mobile` dessous ; `space-12` de marge dessous sur ordinateur, `space-6` sur téléphone.
- Il nomme aussi l'onglet du navigateur : « Applications · MyInfra ».
- Le consommateur fournit `title`, et au besoin `icon` (lucide), `mark` (un logo d'application) ou `action` (un `Button`).

Source : `web/src/ui.tsx`.
