# TextButton

L'action secondaire : du texte sans fond, pour tout ce qui n'est pas l'action principale de l'écran.

- Texte `color-ink` (ou `color-bad` avec `tone="danger"`), fond `color-status` au survol, `radius-md`.
- Sa marge négative aligne le texte sur la colonne : posez-le sans padding autour.
- Le consommateur fournit le libellé et, au besoin, un `Icon`.

Source : `web/src/ui.tsx`.
