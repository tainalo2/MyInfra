# Logos

- `myinfra-mark.svg` — la marque : l'icône lucide « Boxes » (trois cubes) en `color-canvas` cerclée de `color-ink`, sur une tuile carrée `color-ink` au rayon 6/32. Le fichier bascule lui-même en sombre (`prefers-color-scheme`) : tuile `color-canvas`, cubes `color-ink`. Favicon de l'interface ; à 16–32px.
- `myinfra-app-icon.png` — l'icône d'application macOS, 1024×1024. Pour l'installeur, le Dock, un aperçu de lien.

Dans l'en-tête, la marque n'est pas cette image : c'est l'icône lucide `Boxes` à 16px, trait 1,5, en `color-ink`, suivie du mot « MyInfra » en `body-medium`. Pas de logotype dessiné.
