# Instantané de la bibliothèque

Les trois fichiers d'une release de la bibliothèque (`library.tar.gz`, `SHA256SUMS`, `SHA256SUMS.sig`), intégrés au binaire : MyInfra les propose tant qu'il n'a pas récupéré de release plus récente, ou sans réseau.

Pour passer à une autre release : `./library-snapshot v1.2.0` (ou `library-snapshot.ps1` sous Windows).
